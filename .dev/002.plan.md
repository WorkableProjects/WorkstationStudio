# Workstation Studio v0.0.2 – Windows 95/98 Refresh

## Overview
Replace the macOS-inspired UI with an authentic Windows 95/98 aesthetic, complete with period-accurate design patterns, sounds, and native application suite.

---

## Tasks

### 1. Windows-Inspired Layout & Start Menu
**Objective**: Transition from top menu bar to Windows 95-style taskbar and Start menu.

**Acceptance Criteria**:
- Logo positioned in **bottom-left corner** of taskbar (source file: `Logo.png`)
- Clicking logo opens **Windows Start menu** displaying:
  - Available applications (Calculator, Notes, Settings, File Manager)
  - System options (Shutdown, Restart, Sleep)
  - Quick access to recent files
- Taskbar shows:
  - Currently open/minimized application windows
  - System clock (bottom-right)
  - System tray area (volume, network status)
- Window chrome matches Windows 95 (title bar, minimize/maximize/close buttons)

---

### 2. Windows 95 Startup Screen
**Objective**: Create an authentic boot-up experience with dynamic version display.

**Acceptance Criteria**:
- **Display elements**:
  - "Workstation Studio" branding (centered, large font)
  - Version number (e.g., "v0.0.2") – pulled from `package.json` or environment variable
  - Animated progress bar (Windows 95/98 style) with status messages
- **Editability for agents/developers**:
  - Version auto-pulled from project config (no manual edit needed)
  - Progress messages configurable via startup config file
  - Skip/bypass option available during development (e.g., `--skip-splash` flag)
- **Duration**: ~3–5 seconds, or until assets load (whichever is longer)
- **Fallback**: If startup fails, show error dialog styled as Windows 95 error box

---

### 3. Additional Desktop Themes
**Objective**: Expand visual customization with period-accurate theme variants.

**Acceptance Criteria**:
- **Themes provided**:
  - Windows 95 (default/primary)
  - Windows 98 (SE variant with blue window chrome)
  - Windows 3.1 (minimal, monochrome retro option)
- **Theme switching**:
  - Dropdown in Settings app or Taskbar system tray
  - Instant preview without restart
  - Persistence via `localStorage` or config file (`~/.workstationrc` or similar)
- **Consistency**: All windows, dialogs, and native apps respect the selected theme

---

### 4. Windows 3.1 Error Sound
**Objective**: Provide audio feedback for error states using authentic period sound.

**Acceptance Criteria**:
- **Sound file**: `Windows 3.1 Error Sound.mp3` (located in repo root `/assets` or similar)
- **Trigger scenarios**:
  - Form validation failures
  - Application crashes or close errors
  - Permission denied / access restrictions
  - System warnings
- **Implementation**:
  - Centralized error handler plays sound via Web Audio API (or `<audio>` element)
  - Volume control in Settings app
  - Option to mute error sounds
- **Fallback**: Visual error indicator (red flash, icon) if audio unavailable

---

**Acceptance Criteria**:
