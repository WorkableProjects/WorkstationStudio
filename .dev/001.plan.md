Welcome, Codex. This is the Workstation Studio, the frontend version of Workstation CLI. In the **CLI** folder, then the subfolder **Workstation CLI**, you’ll find a GitHub project named Workstation CLI. It is the Python‑based implementation you will port to a TypeScript, web‑based version.

There are a few key differences. You will create a browser‑based operating‑system application and implement a bridge between the frontend (the browser) and the backend (the code running on any machine with the project built). You’ll build standard frontend apps such as:

- a notes application  
- a simple calculator  

and you’ll also add a terminal application.

The terminal app requires the same bridge. It should launch Workstation CLI via the path `CLI/Workstation CLI/Workstation.py`. Without the bridge, the terminal cannot access that file, so it will not work.

ALso, add the directory 'CLI' to git-ignore, since WorkStationCLI builds in a different project. Your only building the front-end and CLI bridge.

What not to focus on in the inital build:

UI Elements (usability over quality)
Animations

What to focus on:
CLI Bridge w/ Terminal App
Notes & Calc application
Window Mangement
