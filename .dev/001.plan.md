# Workstation Studio - Initial Build Plan

## Project Overview
Workstation Studio is a browser-based operating system application that serves as the frontend to Workstation CLI. This is a **frontend-only build** — the backend (Workstation CLI) lives in a separate `CLI/` directory and builds independently.

---

## Architecture: Frontend-Backend Bridge

**Frontend:** Browser-based OS application (this repo)  
**Backend:** Workstation CLI located at `CLI/Workstation CLI/Workstation.py`

The bridge enables the browser frontend to communicate with and launch the backend CLI. This bridge is **critical** for:
- Terminal application (must launch Workstation CLI via the Python script)
- Notes application
- Calculator application

---

## Core Applications to Build

### 1. **Terminal Application** (Priority: HIGH)
- Launches and communicates with `CLI/Workstation CLI/Workstation.py`
- Uses the frontend-backend bridge to send commands and receive output
- Must handle process lifecycle and standard I/O streams

### 2. **Notes Application** (Priority: HIGH)
- Browser-based note-taking interface
- Basic CRUD operations
- Uses the bridge if backend persistence is required

### 3. **Calculator Application** (Priority: HIGH)
- Simple arithmetic calculator
- Browser-based UI and logic

### 4. **Window Management** (Priority: HIGH)
- Multi-window desktop environment
- Support for opening/closing/minimizing applications
- Window positioning and layering

---

## Frontend-Backend Bridge Implementation

**Key Requirements:**
- Enable browser ↔ backend communication
- Support process spawning (launch Workstation CLI)
- Handle stdin/stdout/stderr from CLI
- Allow browser to send commands to the terminal

**Target Path:** `CLI/Workstation CLI/Workstation.py`  
*(Note: This directory exists in the project root, so Cursor can edit it even though it may not be visible by default)*

---
